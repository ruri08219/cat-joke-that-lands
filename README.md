One original one-line joke about cats, entered in make.fun's "The One-Line Cat Joke That Lands" bounty:

> I caught my cat opening the treat jar, so I moved it to the top of the fridge — she now opens the fridge.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (UTF-8, single line, 105 characters) and verifies the round-trip byte-for-byte.
